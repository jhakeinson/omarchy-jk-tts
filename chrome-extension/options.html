Get the token

The easiest way is the plugin's settings panel: open the TTS panel → Browser tab and switch on Enable the browser bridge. The panel starts the bridge as a user systemd service, shows the token, and walks you through loading this extension.

From a terminal instead, start the bridge and print its pairing token: 

speak-bridge --print-token

Paste that token above. The same token is stored in ${XDG_CONFIG_HOME:-$HOME/.config}/omarchy-tts/browser-token with mode 0600.

Run speak-bridge --status to check the service, or speak-bridge --install-service to run it as a user systemd service. speak-bridge --disable stops it and keeps it from starting at boot. The bridge binds 127.0.0.1 only.

Using the reader

  • Select text on a normal web page and press Alt+Shift+E.
  • Right-click a selection and choose Read selection aloud.
  • Press the toolbar button, or Alt+Shift+R, for the popup.
  • Stop with Alt+Shift+X or the HUD.

The HUD stays in the top frame, even when the selection is inside an iframe. Chrome blocks browser pages, the Web Store, and its built-in PDF viewer.
